# Budget Tracker App Pro

Modern React + TypeScript web application for personal finance management.

## Run
```bash
npm install
npm run dev
```

## Demo login
- Email: `demo@budget.app`
- Password: `password123`

You can also create a new account from `/register`. Data is saved in browser LocalStorage.

## Features
- Register and login
- Protected routes
- CRUD transactions
- Redux Toolkit state management
- Tailwind responsive UI
- Currency converter with external API and fallback
- i18n EN/FR/AR
- Light/Dark theme
- Component and reducer tests
