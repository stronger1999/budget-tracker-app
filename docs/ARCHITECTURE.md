# Architecture

`src/app` contains Redux store and typed hooks. `src/features` contains slices for auth, transactions, settings, and currency. `src/pages` contains route screens. `src/components` contains reusable UI pieces. `src/services` contains Axios client and API logic.

Libraries: React for UI, TypeScript for safety, Redux Toolkit for state, React Router for navigation, React Hook Form + Zod for validation, Tailwind CSS for styling, Axios for API communication, i18next for translations, Vitest for tests.
